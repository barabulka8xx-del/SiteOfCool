🚀 SiteOfCool 🚀

Экосистема интерактивных веб-приложений, симуляторов и мини-игр.

Коллекция из 9 уникальных проектов, написанных на чистом стеке без использования сторонних фреймворков.

🧠 О проекте

SiteOfCool — это комплексная экосистема браузерных игр и интерактивных симуляторов.

Главная философия проекта — доказать, что для создания качественного, красивого и сложного пользовательского интерфейса (UI) не обязательно использовать тяжелые фреймворки. Вся экосистема работает на Vanilla JavaScript (ES6+), что обеспечивает:

  • Мгновенную загрузку: Никаких этапов сборки и тяжелых бандлов.
  • Минимальное потребление памяти: Прямая работа с DOM-деревом.
  • Глубокое понимание веба: Каждая анимация и каждый расчет написаны вручную.

🎨 Ключевые особенности

  • Современный UI/UX: Темные темы, неоновые свечения, эффекты Glassmorphism и 3D-трансформации.
  • Умный State Management: Прогресс сохраняется локально в браузере. Для каждой игры используются изолированные хранилища.
  • Оптимизация: Работа с Canvas API для графиков и использование DocumentFragment для массового спавна объектов (без зависаний).
  • Mobile-First: Все интерфейсы адаптированы под сенсорные экраны.

🗺 Дорожная карта

  • ✔ Запуск базовой версии Роблокс-Биржи.
  • ✔ Внедрение 3D-карточной игры (Битва Мемов).

  • ☐ PWA (Установка приложений на рабочий стол).
